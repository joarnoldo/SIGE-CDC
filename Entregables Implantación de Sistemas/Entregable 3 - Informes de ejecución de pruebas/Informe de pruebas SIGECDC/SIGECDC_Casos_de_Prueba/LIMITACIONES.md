# Límites y defectos comprobables

- Los 51 casos completos son integración local aislada. Solo PUB-001 y PUB-009 tienen un modo remoto de consulta anónima. No se atribuyen pruebas de escritura a MonsterASP ni se prueba visualmente CSS/JavaScript con un navegador.
- Los casos reutilizan los servicios reales y el host HTTP existente del arnés. Program/hosting/bootstrap quedan fuera. FOR-010 comprueba consulta filtrada y los generadores PDF/Excel reales, incluyendo lectura del contenido; no afirma probar por HTTP los endpoints de descarga definidos dentro de Program.
- PUB-008 / **QA51-DEF-001**: QA02 exige una asociación persistida entre galería y proyecto. El CMS actual permite galerías e imágenes, pero no tiene IdProyecto en solicitud, modelo o persistencia. El test ejercita carga, metadatos, retiro, publicación y lectura; después verifica la asociación requerida y falla al faltar. No sustituye el vínculo por el nombre o descripción.
- FOR-009 / **QA51-DEF-002**, FAIL confirmado: QA02 exige variaciones agrupadas por departamento. La comparación M dispone de totales, participantes, conceptos y proyectos, con datos históricos de departamento por participante; una dimensión histórica no equivale a una agrupación de desviaciones. El test comprobó antes del fallo Forecast 705600, real 672000, diferencia firmada -33600, absoluta 33600 y porcentual -4.7619, además de participantes/proyecto y lectura de la comparación persistida. Falta la agrupación por departamento exigida, sin modificar esa expectativa.
- No se cambió el producto para resolver esas diferencias. Resolverlas requiere una autorización posterior de alcance; asociación galería–proyecto podría requerir esquema y el departamento en M requiere decisión sobre su contrato. No se realiza ninguno dentro de esta entrega.
- Falta de permisos locales, bloqueo de antivirus, runtime/archivo ausente o imposibilidad de iniciar MySQL son impedimentos de infraestructura: se registran resultados explícitos, no aprobaciones ni omisiones silenciosas.
- PDF se inspecciona mediante texto y montos, Excel mediante celdas; no se certifica diseño visual de todas las páginas.
- Las tasas, identidades, fechas y documentos del fixture son sintéticos. No deben reutilizarse para operación real. QA01/QA02 originales no fueron modificados.
